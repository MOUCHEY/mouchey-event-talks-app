# Journal du labo

Une entrée par essai, **échecs compris**, ajoutée en bas. Format :

```markdown
## Essai #<n> — <nom_court> (<date>)
- **Hypothèse** : …
- **Résultat** : score <x> · Sharpe <y> · DD <z> · plis <a/b> · corr. baseline <c> · <ACCEPTÉ/REJETÉ : raison>
- **Lecture** : ce que ça confirme ou réfute, et pourquoi
- **Suite** : idée(s) dérivée(s) ou « piste close »
```

Les remarques pour l'humain (juge trop sévère, bug suspect, données douteuses) vont dans une entrée
`## Note pour l'humain — <date>`.
